# kkh - Kana to Kanji wo Henkan.
日本語の仮名遣いと漢字について、各種の変換を提供するページです。変換の種類には、新仮名遣いを旧仮名遣いへ変換するもの、新漢字を旧漢字へ変換するもの、などがあります。

### 使い方
こちらの [ページ](https://okikae.github.io/kkh/) で文字列を変換して遊んでみてください。

> Note: 変換の対象となるのは、常に「変換前の文章」のテキストエリアにある文字列になります。各種変換ボタンを押すと、変換されたテキストが「変換後の文章」のテキストエリアに表示されます。続けて別の変換をする場合は、「結果を入力へ」ボタンを押して「変換後の文章」を「変換前の文章」へ移動させてください。

### 技術的特徴 (なし)
JSON 形式の辞書を参照して文字列を単純に置き換えていきます。複雑なアルゴリズムはなく、テキストエリアに入力されている文字列に対して、辞書の要素すべてを順番に検索＆置換していくだけです。

### その他
変換をする際に便利なオプションや、別種類の変換機能を追加しています。

この変換がおかしいぞ？と気づいたり、追加して欲しいものがある場合には PR を頂けると幸いです。

また、自分で辞書を作り育てていく楽しみ方もあります。例えば下記のような jisyo を作成して、それぞれ [convert-jisyo-page](https://okikae.github.io/convert-jisyo-page) や [jisyotool](https://github.com/okikae/jisyotool) で JSON 形式の辞書に変換し、HTML のボタンを追加すれば自分だけの変換器になります。

```
# hangeul-jisyo
감사합니다 /ありがとね ;gam sa ham ni da

# chinese-jisyo
太谢谢你了 /ありがとさん ;tài xiè xie nǐ le
```

(でもそれは別のページにしてやることですね)
